# REST API 만들기
## 과제 요구사항
- 본인이 원하는 주제로 간단한 CRUD가 가능한 REST API를 구현합니다.
- 본인이 구현한 각 API에 대한 요청을 Postman을 통해 정상적으로 작동하는지 테스트하여 결과를 첨부합니다.
- 기본적인 [자바 컨벤션](https://newwisdom.tistory.com/m/96)을 준수합니다.
    - intelliJ의 코드 자동 정렬 기능을 사용합니다 (단축키를 찾아봅시다!)
    - 불필요한 개행, 불필요한 공백, 불필요한 import를 주의합니다.

---

## 제출 형식
1. 과제 레포를 fork합니다.
2. fork한 개인 레포를 git clone 하여 파일을 불러옵니다.
3. 자신의 영문 이름으로 된 폴더를 생성합니다.
   - ex. parkyeonji
4. 이름 폴더 아래에 ‘RestApi’이름으로 Spring Boot 프로젝트를 생성합니다.
5. 이름 폴더 아래에 'Postman' 폴더를 생성하고 테스트 결과 이미지를 첨부합니다.
6. 과제 레포로 PR을 날립니다.
